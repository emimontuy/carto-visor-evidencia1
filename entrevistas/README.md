# Entrevistas

Cinco entrevistas semiestructuradas, una carpeta por entrevista. Cada carpeta tiene su propio README con quién es la persona (anonimizada), qué aportó y sus citas clave.

| Carpeta | Perfil | Tipo de actor | Fecha |
|---|---|---|---|
| [`E1_ADIP`](E1_ADIP/) | P1 · La coordinadora del encargo | Coordina y consume | 2026-09-30 |
| [`E2_analista_territorial`](E2_analista_territorial/) | P2 · El analista territorial | Consume para decidir | 2026-10-02 |
| [`E3_usuaria_administrativa`](E3_usuaria_administrativa/) | P3 · La usuaria administrativa | Consume sin ser especialista | 2026-10-07 |
| [`E4_desarrollador`](E4_desarrollador/) | P4 · El desarrollador | Construye la herramienta | 2026-10-10 |
| [`E5_cartografo`](E5_cartografo/) | P5 · El cartógrafo de alcaldía | Produce y actualiza el dato | 2026-10-15 |

**Cómo se hicieron.** Con el guion de [`../guion/`](../guion/). E1 fue la sesión grupal de arranque con la ADIP; E2–E5 fueron individuales, en persona. Cada una se grabó, se transcribió con IA y la corregí escuchando el audio. Después se anonimizó: nombres, apellidos y empleadores se sustituyeron por roles entre corchetes.

**Cómo se analizó cada una.** Por separado, sin mezclar entrevistas: fragmentos con su página, códigos con reglas, hallazgos, historias de usuario. La lectura conjunta está en [`../sintesis/`](../sintesis/).
